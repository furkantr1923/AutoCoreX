AutoCore X’i .NET 10 ve .NET MAUI Blazor Hybrid ile C# kullanarak geliştirdim. Uygulama, telefonu ELM327 OBD-II adaptörüne klasik Bluetooth (SPP/RFCOMM) üzerinden bağlıyor ve aracın ECU’sundan yalnızca okuma yapıyor: Mod 01 ile canlı veri (devir, hız, sıcaklık, voltaj vb.), Mod 03 ile arıza kodları. Arıza kodları için 77 kodluk bir Türkçe sözlük hazırladım. Bakım, yakıt ve yolculuk kayıtları telefonda SQLite veritabanında tutuluyor. Uygulama tamamen çevrimdışı çalışıyor, hesap gerektirmiyor. Yakıt tüketimini depo-full yöntemiyle hesaplıyor, yolculukları MAUI Geolocation ile kaydediyor, PDF raporu da Android’in yerleşik PdfDocument API’siyle oluşturuyor. Şasi numarası Android Keystore korumalı SecureStorage’da şifreli duruyor. Arayüzdeki göstergeleri SVG ve CSS animasyonlarıyla çizdim. Sesleri dosya eklemeden Web Audio API ile kodda ürettim.
